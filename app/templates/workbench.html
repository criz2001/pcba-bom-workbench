功能入口

两大核心能力：先核对已有 BOM，再从设计文件生成新 BOM。

BOM 三方交叉核对

以 PCB 封装、原理图标注值与物料总表编码为基准，逐条核对 BOM 的封装、位号、用量与物料编码。

  • 10 类规则：封装不符 / 名称与总表不符 / 位号缺失 / 位号不存在 / 位号重复 / 用量≠位号数 / 缺编码 / 编码不存在 / 位号格式 / 项次跳号
  • 先校验 PCB 与原理图位号集合一致，再作为同一基准使用
  • 输出 4 个 Sheet：原 BOM 高亮 / 问题清单 / 位号对照 / 值比对（需确认）

BOM 生成

从原理图与 PCB 提取位号、规格和实际封装，匹配物料总表并按模板生成可追溯的 BOM。

  • 规格优先级：原理图 Value ＞ Comment ＞ 器件描述
  • 封装优先级：PCB 实际 PATTERN ＞ 原理图 PCB 模型 ＞ 库引用推断
  • 未匹配项仍保留在 BOM 中并标记『待确认』，不强行匹配
